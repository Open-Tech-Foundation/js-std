# inRange

Checks if a number is within the specified range (inclusive).

## Parameters

- **n** — The number to check.
- **start** — The start of the range.
- **end** — The end of the range.

## Returns

True if n is between start and end.

## Example

```js
inRange(3, 0, 5) //=> true
inRange(-1, 0, 5) //=> false
```
