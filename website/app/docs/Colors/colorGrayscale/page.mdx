🌫️ Converts a color to grayscale.

## Syntax

```ts
import { colorGrayscale } from '@opentf/std';
colorGrayscale({ value: any; to?: ColorFormat }): any
```

- `value`: The input color.
- `to`: The output format (default: `'hex'`).

## Examples

```ts
colorGrayscale({ value: 'red' }); //=> '#808080'
colorGrayscale({ value: '#00ff00' }); //=> '#808080'
```
