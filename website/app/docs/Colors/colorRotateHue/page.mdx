🎡 Rotates the hue of a color.

## Syntax

```ts
import { colorRotateHue } from '@opentf/std';
colorRotateHue({ value: any; degrees: number; to?: ColorFormat }): any
```

- `value`: The input color.
- `degrees`: The degrees to rotate (can be negative).
- `to`: The output format (default: `'hex'`).

## Examples

```ts
colorRotateHue({ value: 'red', degrees: 120 }); //=> '#00ff00' (lime)
colorRotateHue({ value: 'red', degrees: -120 }); //=> '#0000ff' (blue)
```
