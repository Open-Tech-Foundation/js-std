🔄 Inverts the red, green, and blue components of a color.

## Syntax

```ts
import { colorInvert } from '@opentf/std';
colorInvert({ value: any; to?: ColorFormat }): any
```

- `value`: The input color.
- `to`: The output format (default: `'hex'`).

## Examples

```ts
colorInvert({ value: 'white' }); //=> '#000000'
colorInvert({ value: 'black' }); //=> '#ffffff'
colorInvert({ value: 'red' }); //=> '#00ffff'
```

## Try it

```ts
console.log(colorInvert({ value: 'white' })); //=> '#000000'
console.log(colorInvert({ value: 'black' })); //=> '#ffffff'
console.log(colorInvert({ value: 'red' })); //=> '#00ffff'
```
