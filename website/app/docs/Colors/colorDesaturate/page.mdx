🧊 Decreases the saturation of a color.

## Syntax

```ts
import { colorDesaturate } from '@opentf/std';
colorDesaturate({ value: ColorInput; amount: number; to?: ColorFormat }): any
```

- `value`: The input color.
- `amount`: A number between `0` and `1`.
- `to`: The output format (default: `'hex'`).

## Examples

```ts
colorDesaturate({ value: 'red', amount: 0.5 }); //=> '#bf4040'
colorDesaturate({ value: 'red', amount: 0.5, to: 'rgba-object' }); //=> { r: 191, g: 64, b: 64, a: 1 }
```
