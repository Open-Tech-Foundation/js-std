Repeats the given string n times.

## Syntax

```ts
import { repeat } from '@opentf/std';
repeat(str: string, n = 1): string;
```

`n` must be a non-negative finite integer.

## Examples

```ts
repeat('*', 3) //=> '***'

repeat('abc', 2) //=> 'abcabc'

repeat('abc', 0) //=> ''
```
