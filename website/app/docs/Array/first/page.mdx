🎯 Returns the first element of the array.

## Syntax

```ts
import { first } from '@opentf/std';
first<T>(arr: T[] = []): T | undefined
```

## Parameters

- `arr`: The source array.

## Returns

The first element, or `undefined` if the array is empty.

## Examples

```ts
first([1, 2, 3]) //=> 1

first(['a', 'b', 'c']) //=> 'a'

first([]) //=> undefined

first() //=> undefined
```

## Try it

```ts
const users = [
  { name: 'Ada', role: 'admin' },
  { name: 'Lin', role: 'editor' },
];

// Grab the first admin, or fall back to a default
const admin = first(users.filter((u) => u.role === 'admin'));
console.log(admin); //=> { name: 'Ada', role: 'admin' }

// Safe on empty arrays — returns undefined instead of throwing
console.log(first([])); //=> undefined
```
