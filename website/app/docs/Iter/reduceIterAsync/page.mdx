# reduceIterAsync

🧩 Accumulates values from an async iterator using a reducer function.

## Syntax

```ts
import { reduceIterAsync } from '@opentf/std';
reduceIterAsync<T, U>(iter: AsyncIterable<T>, fn: (acc: U, val: T) => U | Promise<U>, options: { initialValue: U }): Promise<U>
```

## Parameters

- `iter`: The async iterable to reduce.
- `fn`: The reducer function.
- `options.initialValue`: The initial value for the accumulator.

## Returns

A promise that resolves to the final accumulator value.

## Examples

```ts
async function* gen() { yield 1; yield 2; yield 3; }
await reduceIterAsync(gen(), (acc, x) => acc + x, { initialValue: 0 }) //=> 6
```
