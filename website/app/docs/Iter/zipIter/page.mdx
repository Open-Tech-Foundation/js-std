🧩 Yields one group per position, taking one item from each iterable.

## Syntax

```ts
import { zipIter } from '@opentf/std';
zipIter<T>(...iterables: Iterable<T>[]): Generator<(T | undefined)[]>
```

## Parameters

- `...iterables`: The iterables to zip.

## Returns

A new generator of groups.

Runs until every source is exhausted, padding the ones that finished early with
`undefined` — which is what [zip](/docs/Array/zip) does for arrays. That means
an infinite source never lets it end; pair it with
[takeIter](/docs/Iter/takeIter).

Each source is advanced exactly once per group and never read ahead, so the
items sit in memory one row at a time. The sources are closed when the consumer
stops early.

## Examples

```ts
[...zipIter([1, 2], ['a', 'b'])] //=> [[1, 'a'], [2, 'b']]

[...zipIter([1, 2, 3], ['a'])] //=> [[1, 'a'], [2, undefined], [3, undefined]]
```
