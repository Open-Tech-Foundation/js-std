# lerp

📐 Linearly interpolates between two values.

## Syntax

```ts
import { lerp } from '@opentf/std';
lerp(options: { start: number; end: number; progress: number }): number;
```

## Parameters

| Name               | Type     | Description |
| ------------------ | -------- | ----------- |
| `options.start`    | `number` | The starting value. |
| `options.end`      | `number` | The ending value. |
| `options.progress` | `number` | The interpolation parameter `t` in `start + (end - start) * t`. `0` returns `start`, `1` returns `end`, values between them interpolate, and values outside 0-1 extrapolate. |

## Returns

The interpolated value.

## Examples

```ts
lerp({ start: 0, end: 10, progress: 0.5 }) //=> 5
lerp({ start: 100, end: 200, progress: 0.25 }) //=> 125
```
