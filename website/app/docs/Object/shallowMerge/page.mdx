Shallow Merges objects or arrays.

## Syntax

```ts
import { shallowMerge } from '@opentf/std';
shallowMerge(obj1, ...objN);
```

<Callout type="info" emoji="✅">
Immutable: This does not mutate the given arrays or objects.
</Callout>

<Callout type="warning" emoji="🛡️">
  Sources are copied without `Object.assign`, so an own `__proto__` key — what
  `JSON.parse` produces for `{"__proto__":{...}}` — cannot replace the result's
  prototype. This matters when merging defaults with an untrusted request body.
</Callout>

## Examples

```ts
const a = { a: 1 };
const b = { b: 2 };
shallowMerge(a, b); //=> { a: 1, b: 2 }

const a = [1];
const b = [2];
const c = [3];
shallowMerge(a, b, c); //=> [3]
```
